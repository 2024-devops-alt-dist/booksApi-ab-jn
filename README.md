# ibooksApi-ab-jn

## Utilisation de l'API Google Books

Ce projet utilise l'API Google Books pour rechercher des livres et afficher des informations détaillées.

L'API Google Books permet d'accéder à des informations sur des millions de livres. Elle offre des fonctionnalités de recherche, d'affichage des détails des livres, et bien plus encore.

## Prérequis

- Compte Google pour obtenir une clé API.
- Connaissance de base en JavaScript (ou tout autre langage supportant les requêtes HTTP).

## Installation

Clonez ce dépôt :

   git clone https://github.com/2024-devops-alt-dist/booksApi-ab-jn.git

## Suggestions de modifications pour le projet initial

1. **Intégration de la Navbar** :
   - Problème d'intégration de la navbar dans la `bookPage`. Vérifiez le code pour que la navbar s'affiche correctement.

2. **Double déclaration de classe CSS** :
   - Il y a des doublons dans les classes CSS. Vous pouvez corriger ça pour éviter les conflits de style.

3. **Lien vers la page d'accueil** :
   - Ajoutez un lien permettant de revenir à la page d'accueil depuis la `bookPage`. Cela améliorera la navigation dans l'application.
